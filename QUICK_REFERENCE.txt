  $ cp etl_config_template.json my_project.json

CONFIGURATION TEMPLATE
================================================================================

{
  "project_name": "Your_Project_Name",
  "source": {
    "type": "Oracle",              # Source system (e.g., Oracle, MySQL, etc.)
    "name": "Source System"
  },
  "target": {
    "type": "Teradata",            # Target system (e.g., Teradata, Snowflake)
    "name": "Target System"
  },
  "primary_key": "id",
  "schema": {
    "id": "integer",               # Your fields and data types
    "name": "string",
    "created_date": "date"
  },
  "validation_rules": {
    "id": {"required": true, "type": "integer", "min": 1}
  },
  "etl_stages": [
    {"stage": "extraction", "enabled": true},
    {"stage": "transformation", "enabled": true},
    {"stage": "loading", "enabled": true}
  ]
}

================================================================================
CSV OUTPUT FORMAT
================================================================================

All generated CSVs include 9 columns:
  1. Test Case ID        → TC-1000, TC-2000, etc.
  2. Test Case Name      → Row Count Validation, etc.
  3. ETL Stage           → Extraction, Transformation, Loading
  4. Test Type           → Count, Validation, Duplicate, etc.
  5. Source              → Your source system (e.g., Oracle)
  6. Target              → Your target system (e.g., Teradata)
  7. Description         → What the test does
  8. Expected Result     → What success looks like
  9. Status              → Not Executed, Passed, Failed

Example Row:
  TC-1000, Row Count Validation, Extraction, Count, Oracle, Teradata,
  Verify correct number of rows extracted..., Row count matches..., Not Executed

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Config file not found
Solution: Use absolute path or check filename is correct

Problem: Empty CSV generated
Solution: Check etl_stages has "enabled": true

Problem: Missing test cases
Solution: Verify schema and validation_rules are populated

Problem: Import error in Jira
Solution: Ensure CSV is UTF-8 encoded

See FRAMEWORK_GUIDE.md for more troubleshooting
